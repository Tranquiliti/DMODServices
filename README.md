A utility mod for [Starsector](https://fractalsoftworks.com/) that adds a dialog option in size 6 or higher markets, allowing you to add damage mods to your ships without needing to enter combat. Also includes non-default options like making ships unrestorable or fully-automated.

This mod is safe to add to and remove from existing saves.
